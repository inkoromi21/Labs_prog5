# Метод Ньютона

Лабораторная работа по поиску корней и экстремумов функции на заданном отрезке. Приложение для Windows x64 строит график функции.

## Как запустить

Откройте `Метод Ньютона.exe`. Введите функцию, границы отрезка и число знаков после запятой. Выберите «Корень», «Минимум» или «Максимум» и нажмите «Рассчитать».

## Как работает поиск

Для корня базовый метод Ньютона решает уравнение `f(x) = 0`. Для экстремума он ищет точку, где `f′(x) = 0`, затем проверяет смену знака производной.

Цель поиска экстремума — найти глобальный минимум или максимум на заданном отрезке. Если глобальность подтвердить не удаётся, допустим локальный экстремум. Текущая версия сравнивает найденную точку со значениями на границах и подписывает подтверждённый экстремум как локальный.

Если метод не сходится или не удаётся подтвердить результат выбранного режима, программа показывает «Не могу найти».

# Метод Ньютона

## Задание

Реализовать метод Ньютона для поиска корня, минимума и максимума функции.
Построить график и показать шаги вычислений.

## Выполнено

Создано приложение с вводом функции, интервала и числа знаков для вывода.
Метод начинает с границы с большей f(x). Сначала проверяется количество корней
или внутренних экстремумов выбранного типа. При их отсутствии или множественности
поиск не запускается и касательные не строятся. Границы не заменяют экстремум.
График показывает функцию, границы интервала, одну касательную и предыдущие точки.
Масштаб изменяется. В ответе указана только координата x.

## Вывод

Расчёт не зависит от числа знаков для вывода. Численная проверка не доказывает
полноту найденных корней и экстремумов. Подпись «глобальный» для внутреннего
экстремума с горизонтальной касательной принята по условию и не доказывает глобальности.

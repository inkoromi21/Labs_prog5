# Лабораторная работа №4

WPF-приложение ищет методом Ньютона корень, минимум и максимум `f(x)`. Расчёты и численные производные вычисляются в программе; график загружается через Image-Charts.

## Запуск

На Windows откройте `WpfApp2.slnx` в Visual Studio с .NET 10 SDK. Готовый файл для Windows x64 — `Метод Ньютона.exe`. Интернет нужен для построения графика.

## Использование

Введите границы `a < b`, формулу, число знаков после запятой от 0 до 15 и выберите задачу. Значение `3` задаёт точность `0,001` по x. Нажмите «Построить график» или кнопку поиска. Отрицательную функцию и модуль программа берёт сама.

Поддерживаются `+`, `-`, `*`, `/`, `^`, скобки, `x`, `pi`, `e`, а также `sin`, `cos`, `tan`, `sqrt`, `ln`, `log`, `exp`, `abs`. Умножение пишется явно: `2*x`. Углы задаются в радианах; `ln` — натуральный логарифм, `log` — десятичный.

Для корня используется шаг `x = x - f(x)/f′(x)`, для экстремума — `x = x - f′(x)/f″(x)`. Производные вводить не нужно. Начальная точка выбирается по 257 точкам функции. Шаг уменьшается, если выходит за границы или ухудшает приближение.

Для метода нужна достаточно гладкая функция. Нулевая производная в знаменателе, излом или отсутствие сходимости могут помешать расчёту. Проверка по точкам не гарантирует обнаружения всех корней и разрывов. Число знаков задаёт порог для шага по x, но не доказывает такую же погрешность ответа для произвольной функции. На графике показана исходная функция.

# Метод Ньютона

## Задание

Реализовать метод Ньютона для поиска корня, минимума и максимума функции.
Построить график и показать шаги вычислений.

## Выполнено

Создано приложение с вводом функции, интервала и точности. Производные вычисляются
автоматически. Добавлены график, касательные и просмотр шагов метода.
При невозможности продолжить вычисления программа объясняет причину остановки.

## Вывод

Метод Ньютона позволяет находить приближённые решения, но его сходимость зависит
от начальной точки и свойств функции. Остановка метода не означает отсутствия
решения, а найденный экстремум не обязательно глобальный.
